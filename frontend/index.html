🎯 3-Step Wearable Glove Calibration Wizard
Per-User Normalization

Flex sensors experience physical resistance drift and variations in hand anatomy. Record the 3 key baseline positions to calibrate and normalize readings into standard [0.0, 1.0] deflection ranges.

1. Relaxed Hand

Rest hand naturally without force. Calibrates neutral resting flex and gyro zero-rate bias.

2. Fingers Straight

Extend all 5 fingers fully flat. Calibrates minimum bending (0.0 limit).

3. Fingers Bent (Fist)

Close hand tightly into a fist. Calibrates maximum bending (1.0 limit).

🧠 Baseline Machine Learning Training
Scikit-Learn

Trains and evaluates 3 core machine learning algorithms across the 11 sensor features:

  • Decision Tree: Fast, explainable rule splits based on finger flexion thresholds.
  • Random Forest: Robust ensemble of decision trees with high generalization.
  • Support Vector Machine (SVM): RBF non-linear kernel hyperplane classifier.
⚡ Advanced Dynamic Model (LSTM)
PyTorch Time-Series

Dynamic ISL gestures (like HELLO waving, YES nodding, EMERGENCY shaking) exhibit continuous trajectory dynamics. Trains a multi-layer Long Short-Term Memory (LSTM) network over 30-step sliding windows.
